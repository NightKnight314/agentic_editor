# Video-editing research pack

Collected for Nighthack on 2026-07-25. Detailed notes retain source links; reusable skills turn the research into agent workflows.

## Notes

- `notes/editorial-methodologies.md` — story, continuity, dialogue, documentary, montage, pacing, short-form, and multicam methods.
- `notes/post-production-methodologies.md` — audio, color, captions, reframing, encoding, delivery, and QC.
- `notes/ai-assisted-editing-methodologies.md` — media analysis, planning, operation models, confidence, provenance, and evaluation.
- `notes/platform-integration-blueprint.md` — concrete implications and build order for the current codebase.
- `notes/style-map-authoring.md` — convert qualitative creative direction into planner rules, budgets, fallbacks, and review criteria.
- `notes/hackathon-sketch-synthesis.md` — translate the four handwritten architecture sketches into shared event, pattern, revision, and feedback concepts.
- `notes/event-and-edit-representations.md` — formalize assets, observations, evidence assertions, source events, beats, intents, commands, revisions, clocks, provenance, and interchange.
- `notes/edit-pattern-and-style-systems.md` — define semantic recipes, renderer bindings, dependency graphs, effect budgets, reference-derived style, validation, and initial recipe contracts.
- `notes/human-agent-coediting.md` — design proposal/diff/preview/approval UX, revisions, alternatives, feedback data, safeguards, and user evaluation.
- `notes/effects-editorial-methodology.md` — choose, motivate, budget, preview, and validate visual/audio effects while protecting comprehension, accessibility, and source integrity.

## Skills

- `skills/plan-video-edit/` — build and review evidence-grounded edit plans.
- `skills/finish-video-post/` — finish audio, color, captions, delivery, and QC.
- `skills/engineer-ai-editing/` — design reliable, auditable AI editing workflows.
- `skills/author-edit-patterns/` — turn editing techniques and style references into constrained, reusable recipes.
